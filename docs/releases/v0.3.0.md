## Breaking changes

- none

## Highlights

**Settings grew up.** The settings window is now a proper macOS surface: toolbar tabs,
hidden titlebar, autosave (there is no Save button — edits apply live, and hand-editing
`config.json` still works and updates the open window), and press-to-record hotkey pills
instead of typing accelerator strings.

**Themes.** Fourteen built-ins — launcharr, dracula, terminal (matrix green), amber CRT,
catppuccin, gruvbox, monokai, nord, one-dark, rosé pine, solarized, solarized light,
synthwave '84, tokyo night — applied live to the panel and settings. Your own theme is a
JSON edit: partial token overrides under `"themes"` in config.json.

<!-- screenshot: settings General tab · gif: theme flip through 3-4 themes -->

**Quicklinks go both ways.** `chill captain hook ⏎` hits the search template;
a bare `chill ⏎` now opens the site itself.

**Housekeeping.** Config and scripts access moved from the tray into settings
(General ▸ Hackables); the tray menu slimmed to summon / settings / reindex / quit.
