# v1.1 — script protocol + Sol-parity features

## Goal

Feature-match the wanted Sol features without breaking launcharr's invariants, by building
the v2 script protocol now and shipping most features as bundled, user-editable scripts.

## Context

v1 is feature-complete and in holdout. Mitch requested Sol parity (2026-08-08); scope was
negotiated against the PRD invariants: zero-network and zero-permissions stand, so Google
Translate, public IP, and Calendar are deferred; clipboard is copy-on-Enter only (no
Accessibility). Architecture decision: scripts-first.

## Approach

- **Grammar:** first-token trigger dispatch joins `!` in one dispatch table (per PRD §4.4).
- **Script contract:** executables in `~/.config/launcharr/scripts/`; `<script> manifest` →
  `{trigger, name, description}`; `<script> query <args>` → `{items: [{title, subtitle?,
action: {type: copy|open, value}}]}`. Rust discovers/invokes with timeouts; TS renders.
- **Bundled scripts** (python3 stdlib only): lorem, json (pbpaste→format→copy), ip (local).
- **Inline math** in TS core (hot path, no subprocess): tokenizer + shunting-yard, copy on
  Enter.
- **Clipboard:** NSPasteboard changeCount poll, concealed-type respected, SQLite history
  (cap 200), `clip` trigger mode, Enter copies.
- **Custom links** (`links` in config → index items) and **custom shortcuts** (`shortcuts`
  map hotkey → item query in config).

## Acceptance criteria

- [x] `lorem 3 ⏎` copies three paragraphs; `json ⏎` formats clipboard JSON and copies back;
      `ip ⏎` copies the local IP
- [x] `2*(14.5+3)` shows `= 35` as top row; Enter copies
- [x] `clip` lists recent clipboard text; typing filters; Enter copies; concealed items never
      recorded
- [x] A `links` entry appears in results and opens in the browser
- [x] A `shortcuts` entry summons its target from anywhere
- [x] Dropping a new executable in `~/.config/launcharr/scripts/` registers its trigger
      without a restart

## Out of scope

Google Translate, public IP, Calendar (deferred — see DECISIONS), auto-paste (Accessibility
stays banned), script-defined UI beyond result rows.

## Risks / open questions

- Per-keystroke script invocation cost → debounce 120ms + 3s timeout; scripts are local.
- Pasteboard polling weight → 800ms interval, changeCount check only (no read when unchanged).

## Outcome (2026-08-08, overnight build)

Delivered in full within the negotiated scope. Machine-verified end-to-end: bundled scripts
(lorem/json-format/ip) install on first run and answer the contract; clipboard watcher records
to SQLite and honours concealed/transient types; inline math evaluator (41 TS tests total);
links and shortcuts hot-reload from config with clean registration. One real bug caught by
tests pre-prod: python stdlib shadowing by json.py (renamed + sys.path guard — see JOURNAL).
Awaiting Mitch's hands-on pass for panel rendering and the custom-shortcut keypress.
