## Breaking changes

- none for the launcher. Two things to know if you upgrade from 0.3.x:
  - **AeroSpace becomes a Homebrew dependency** of the cask (`depends_on cask:
"nikitabobko/tap/aerospace"`). If you already run AeroSpace with your own
    `~/.config/aerospace/aerospace.toml`, launcharr **does not touch it** — Settings →
    Desktop asks whether to use launcharr's config (yours is backed up beside it) or keep
    yours. Tiling can be switched off entirely.
  - The bar is **off by default**; turn it on in Settings → Menubar.

## Highlights

**launcharr is a keyboard control surface now, not just a launcher.** Everything below is
in daily use on the author's Mac.

**The bar.** An Omarchy-flat menubar replacement: workspaces (clickable, hotkey-tracked),
front app, clock, Wi-Fi SSID, battery with a hover card (capacity, time left, cycles,
draw, health), coding-agent cells. Zones (left / center / right) arranged by drag in
Settings, with a separate profile for notched displays. Themed by the same tokens as the
launcher; ~19 MB marginal.

**Panels.** Trigger words open keyboard-driven TUI panels inside the launcher window:
`wifi ⏎` (connect, scan, power), `dns ⏎`, `audio ⏎` (volume, devices, mute),
`clipboard ⏎`, `awake ⏎` (keep-alive sessions with rails — retires Amphetamine),
`agents ⏎`, `usage ⏎` (local token monitor for Claude + Codex), `aerospace ⏎` (the tray
menu as rows), `help ⏎`, and **`ss ⏎` — a grid of your latest screenshots; Enter puts the
file on the clipboard, `⌘V` into your agent.** Esc walks back; focus returns exactly
where it was.

**Agents.** Claude and Codex sessions as bar cells (boxed by tmux session, blocked
breathes red, click to jump to the pane), plus opt-in `?` mode: press `?` and ask your own
`claude`/`codex` CLI, streamed. Off by default; account-limit fetches are opt-in per
provider.

**The desktop layer.** Tiling via AeroSpace with a config launcharr writes for you
(modifier, gaps, workspaces — the file is yours the moment you stop letting launcharr
manage it: edit, use your own via symlink, or save a copy), opt-in JankyBorders in your
theme's accent, and the pre-Tahoe window corner radius back if you want it.

**Settings.** Sub-tabs, a Quicklinks page, wider window, and drag-and-drop that
actually works (wry's file-drop hook was swallowing every HTML5 drag event).

## Performance receipts

Measured on the release build, 2026-08-17 (M-series, bar on, agents monitor on):

| Metric                         | Budget   | This release |
| ------------------------------ | -------- | ------------ |
| Hotkey → panel visible         | < 100 ms | 1.8 ms       |
| Cold start → hotkey registered | < 1 s    | 200 ms       |
| Idle memory (panel hidden)     | < 120 MB | 114 MB       |

Idle memory is the number to watch: the bar is a second WebKit view and it costs ~19 MB
over 0.3.1's 98 MB. Bar off ≈ 0.3.1.
