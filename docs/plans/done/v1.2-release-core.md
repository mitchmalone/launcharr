# v1.2 — release core

## Goal

First public-release feature set, feature-matching the big players' daily core: system
commands, secondary actions (⌥⏎), opt-in browser bookmarks, emoji picker, a settings
screen, and the release blockers (README, version bump, signing/notarization scaffolding).
File search deliberately last/never (Mitch, 2026-08-09).

## Approach (per feature)

1. **System commands** — static table à la settings panes (`cmd:` ids): sleep, sleep
   displays, lock screen, empty trash, toggle dark mode, toggle mute, eject all, restart,
   shut down, log out, caffeinate/decaffeinate. AppleScript/pmset; System Events/Finder
   trigger the standard Automation consent (documented).
2. **Secondary actions** — rows gain an optional `alt` enter; ⌥⏎ triggers it; the hint
   column live-switches while ⌥ is held. Apps: Reveal in Finder. Links/bookmarks/URLs:
   copy URL. Clips: delete from history. Scripts: optional `altAction` in the protocol.
3. **Bookmarks (opt-in)** — `indexBookmarks: false` default. Chrome-family JSON
   (Chrome/Arc/Brave/Edge, all profiles) + Safari plist (FDA-dependent, fail silent).
   Indexed as links with hint `bookmark`, capped.
4. **Emoji picker** — `:` joins the first-char dispatch table (`:fire`). Embedded
   unicode-emoji dataset (build-time asset), fuzzy over names/keywords, copy on Enter.
5. **Settings screen** — second WebView window from tray "Settings…" + `launcharr —
Settings` item; terminal-styled form over the whole config; `write_config` command
   saves, existing watcher hot-applies.
6. **Release blockers** — README (pirate flag included), version 0.2.0,
   docs/RELEASING.md with the signing/notarization checklist (needs Mitch's Apple
   Developer ID), signing config scaffolded in tauri.conf via env.

## Acceptance criteria

- [x] `sleep dis ⏎` sleeps displays; commands indexed + frecency-ranked like everything
- [x] ⌥⏎ on an app reveals in Finder; hint column shows the alt action while ⌥ held
- [x] Bookmarks appear only when `indexBookmarks: true`; Chrome-family verified
- [x] `:shrug ⏎` copies 🤷; emoji search feels instant (budget holds)
- [x] Settings window edits and saves every config field; changes hot-apply
- [x] README + RELEASING.md complete; version 0.2.0; all gates green; pushed

## Out of scope

File search (deferred), image clipboard, light mode, unit conversions, auto-updater
(needs signing first).

## Outcome (2026-08-09)

All six features shipped in one sitting, each its own commit, 66 TS + 35 Rust tests green.
v0.2.0 built, installed, running (cold start 175ms, RSS 93MB). Machine-unverifiable, needs
Mitch: system-command Automation consents on first use, ⌥⏎ hint-switching feel, settings
window layout, `:fire ⏎`, bookmarks toggle against a real Chrome profile. Signing +
notarization need Mitch's Apple Developer ID — full checklist in docs/RELEASING.md.
